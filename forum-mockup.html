Cloudflare 環境下如何正確設定 CNAME（含 Proxy 模式說明）
C
Cliff (SkyCloud) ADMIN ·2天前·534 次瀏覽

在 Cloudflare 管理你的網域時，預設會啟用 Proxy（橘色雲朵） 模式，這會讓 DNS 記錄的解析結果指向 Cloudflare 的 IP，而非我們的 CNAME 目標。

問題症狀

設定完 CNAME 後，用 nslookup 查詢結果顯示的是 Cloudflare 的 IP，而非 gocname.com 的位址。

正確設定步驟

  • 登入 Cloudflare Dashboard，進入你的網域
  • 點選左側 DNS → Records
  • 找到你的 CNAME 記錄，點擊 Proxy 圖示（橘色雲朵）
  • 改為 DNS Only（灰色雲朵）
  • 儲存後等待 1–5 分鐘生效

驗證指令

nslookup www.yourdomain.com
# 應回傳 xxxxxx-site-01.gocname.com
